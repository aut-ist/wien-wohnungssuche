# Wohnungssuche Wien

Private Wohnungssuche: Eigentumswohnungen von willhaben, ImmoScout24, derStandard,
FindMyHome, Raiffeisen Immobilien und s REAL werden täglich geholt, Duplikate über die
Portale hinweg zu einem Eintrag zusammengeführt, nach eigenen Kriterien gefiltert und auf
einer Karte gezeigt.

- **Kriterien:** ab 70 m², ab 4 Zimmer, bis 1 Mio. €, keine Gasheizung
- **Gebiet:** 8., 18., 19. Bezirk, 9. Bezirk ohne Lichtental-Nord, dazu Teile des
  1. Bezirks (Börse/Schottenviertel) und des 2. Bezirks (Karmeliterviertel)
- **Karte:** `docs/` (GitHub Pages)

Datenquellen: willhaben.at, Bezirksgrenzen und Öffi-Linien von data.wien.gv.at
(CC BY 4.0, Stadt Wien), Geocoding über OpenStreetMap Nominatim.
